# Knowledge Hub — Project Instructions
## Tech Stack
- Vanilla JavaScript (ES modules), HTML5, CSS3
- Vercel Serverless Functions (Node.js 18+)
- localStorage (current), Supabase (future)
- OpenAI API (gpt-4o-mini, text-embedding-3-small, gpt-4o vision)
- NO frameworks. NO build step.
## Rules
- Serverless functions use: export default async function handler(req, res) { }
- Always return JSON.
- Handle errors gracefully.
- Read existing code before modifying.
